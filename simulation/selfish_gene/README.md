# 🧬 시뮬레이션: 이기적 유전자 (반복되는 죄수의 딜레마)

다양한 생존 전략(신사, 배신자, 복수자)을 가진 개체들이 무작위로 매칭되어 죄수의 딜레마 게임을 수행하고, 획득한 에너지에 따라 생존과 번식을 이어가는 생태계 시뮬레이션입니다. 단일 함수에 로직을 몰아넣지 않고, **SOP(설계 주도형 사고) 5단계 모듈화**를 적용하여 구현했습니다.

### ⚙️ Architecture (모듈 분리)
단일 함수 복잡도를 낮추기 위해 역할을 철저히 분리했습니다.
- `match()`: 무작위 1:1 짝짓기 및 홀수 개체 부전승 예외 처리
- `play_game()`: 매칭된 객체 간의 G라운드 게임 진행 및 복수자(R)의 첫 턴 배신 로직 처리
- `get_scores()`: 협력(C)/배신(D)에 따른 Payoff Matrix 점수 계산
- `action_by_entity()`: 개체별 전략 패턴을 반환하는 순수 함수
- `get_species()`: 식별 인덱스 번호와 인구 분포를 기반으로 한 종족 판별 (O(1))
- `update_populations()`: 라운드 종료 후 에너지 기반의 아사/생존 및 번식(자가 복제) 처리

### 💡 핵심 트러블 슈팅
- **상태 동기화:** 라운드마다 변하는 인구수(`populations`)를 메인 루프에 실시간으로 반영하여 `IndexError` 방지
- **튜플 언패킹:** 파이썬의 다중 반환값 언패킹 구조를 가독성 있게 분리하여 `ValueError` 해결
